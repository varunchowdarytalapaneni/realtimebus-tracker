# Contributing Guidelines

## Workflow

1. Fork the repository and create a feature branch.
2. Keep pull requests small and focused.
3. Include tests or validation evidence for your change.
4. Request review and address feedback promptly.

## Development Standards

- Follow existing folder boundaries in the monorepo.
- Keep service and UI modules independently buildable.
- Avoid introducing secrets or credentials in commits.

## Pull Request Checklist

- [ ] Scope is clear and limited.
- [ ] Relevant lint/build/test commands were run.
- [ ] Documentation updated when needed.
